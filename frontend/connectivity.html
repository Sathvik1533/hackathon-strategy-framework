1. Frontend ➔ Backend (REST / JSON)

flowchart LR
    Browser["Client Browser"] -->|JSON / Bearer JWT| FetchClient["Native fetch()"]
    FetchClient -->|AbortController 10s| CORSMiddleware["FastAPI CORS"]
    CORSMiddleware -->|Validated Pydantic| Router["/api/v1 Endpoints"]
    Router -->|Generic Envelope| Response["ResponseEnvelope[T]"]

Enforces strict request timeout via AbortController, Pydantic type validation, and standardized envelope responses.

2. Backend ➔ Frontend (SSE Streaming)

flowchart LR
    Worker["Async Job Worker"] -->|publish percent, log| Redis["Redis Pub/Sub"]
    Redis -->|channel:jobs:id| Streamer["FastAPI SSE Generator"]
    Streamer -->|text/event-stream| EventSource["Browser EventSource"]
    EventSource -->|auto-scroll| Terminal["Live Terminal UI"]

Streams real-time agent execution progress from Redis Pub/Sub directly to the browser terminal with reconnect safety.

3. Backend ➔ Database (Postgres + pgvector)

flowchart LR
    Endpoint["FastAPI Route"] -->|Depends(get_db)| Session["AsyncSession"]
    Session -->|TCP 5432 / asyncpg| ConnectionPool["SQLAlchemy Pool"]
    ConnectionPool -->|Cosine Operator <=>| HNSW["pgvector HNSW Index"]
    ConnectionPool -->|ACID Commit/Rollback| Postgres["PostgreSQL 16"]

Connection pooling with auto-rollback on error, Read Committed isolation, and native vector distance queries.

4. Frontend ➔ Database (Supabase RLS)

flowchart LR
    Browser["Browser JS"] -->|HTTPS PostgREST| SupabaseGateway["Supabase API"]
    SupabaseGateway -->|Verify JWT auth.uid()| RLSPolicies["Row-Level Security"]
    RLSPolicies -->|Tenant Matches| AllowedData["Return User Chunks"]
    Browser -.->|TCP 5432 Direct| Blocked["BLOCKED BY FIREWALL"]

Direct TCP port 5432 is strictly blocked. Client queries pass through PostgREST and are filtered by Row-Level Security.

5. Frontend ➔ AI Gateway Indirection

flowchart LR
    Client["Browser Frontend"] -->|POST /jobs/render| BackendAPI["FastAPI Gateway"]
    BackendAPI -->|Token Bucket| RateLimiter["Redis Token Limiter"]
    RateLimiter -->|Strip Injections| Guardrails["Prompt Guardrails"]
    Guardrails -->|Internal Call| AIEngine["LangGraph Multi-Agent"]
    Client -.->|Direct LLM API Key| Leaked["BLOCKED (Prevents Key Leak)"]

Frontend never holds LLM API keys. All calls route through backend rate limiters, token budgets, and prompt guardrails.

6. Backend ➔ AI Layer & FastMCP Tools

flowchart LR
    Supervisor["LangGraph Supervisor"] -->|0ms In-Process| Reranker["FlashRank Neural (<20ms)"]
    Supervisor -->|HTTP SSE / Port 8001| FastMCP["FastMCP Tool Server"]
    FastMCP -->|Isolated Subprocess| CLI["CLI / Scraping Sandbox"]
    Supervisor -->|Backoff + CircuitBreaker| LLM["OpenAI / Anthropic HTTPS"]

Combines zero-overhead in-memory agent execution with isolated FastMCP SSE subprocesses and circuit-breaker protected LLM calls.

7. Deployment & Cloud Topology

flowchart LR
    User["Internet User"] -->|HTTPS Port 443| ALB["AWS Application Load Balancer"]
    ALB -->|Target Group Health /api/v1/health| Fargate["AWS ECS on Fargate (Port 8000)"]
    Fargate -->|VPC Peering / Port 5432| RDS["Amazon RDS (Postgres 16)"]
    Fargate -->|IAM Role Task Credentials| S3["Amazon S3 Bucket (>100KB)"]
    User -->|Direct PUT via Presigned URL| S3

Serverless container execution on ECS Fargate behind an Application Load Balancer, with S3 Presigned URLs for direct large-file uploads.
